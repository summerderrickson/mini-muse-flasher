Mini Muse Flasher

One click firmware installer for the reTerminal Sticky

This page flashes the Mini Muse firmware onto your Seeed Studio reTerminal Sticky. It works in Chrome or Edge on a computer (Safari and Firefox cannot talk to USB devices, so they will not work here).

Before you start

  1. Use a USB-C data cable (some cheap cables only charge, those will not work).
  2. Plug the Sticky into your computer with the cable.
  3. Nothing to install. This page is already hosted online, so just click the button below.

Pick the Sticky's USB serial port when asked, then press Install.

After flashing

  1. The Sticky restarts to the Mini Muse home screen.
  2. Hold UP + DOWN together to open the WiFi setup portal. A MiniMuse-XXXX network appears. Join it from your phone.
  3. Enter your WiFi name and password, your Groq API key (free at groq.com, used for voice transcription), and a device name like sticky-home or sticky-car so replies route to the right unit.
  4. The Sticky connects, syncs its clock, and you are done. Repeat on the second Sticky with the other device name.
Port not showing up? Try a different USB-C cable first (this fixes it almost every time). Then try another USB port, and make sure no other program (like the Arduino IDE serial monitor) is using the port.
Install failed? Unplug the Sticky, plug it back in, reload this page, and try again. There is no boot button on the Sticky. The flasher reboots it into flash mode automatically over USB.
